## Technical Details

### Key Design Decisions

1. **Simplicity over complexity**: LLM does the heavy lifting, we just
   format input and parse output. Much simpler than algorithmic approach.

2. **Backward compatibility**: Old deterministic method still available
   as default. Use --use-llm-synthesis to opt into new method.

3. **Extensibility**: Easy to add more LLM providers or customize prompts.

4. **Structure first**: Phase 3 validation has complete structure even
   though execution uses placeholders. Can be refined incrementally.
